# CloudAI

CloudAI هو مساعد ذكاء اصطناعي متعدد المنصات.

> **حالة الإصدار 1.0.1:** يدعم وضع Agent المهام متعددة الخطوات، وتتوفر حزم التطبيق بصيغة ZIP افتراضيًا. حُفظت حزم 1.0.0 السابقة في [أرشيف الإصدارات القديمة](../Releases/Legacy/v1.0.0/). راجع [وضع Agent](../docs/AGENT_MODE.md) و[قيود HarmonyOS](../docs/HARMONYOS.md).

> **macOS:** يستخدم الإصدار 1.0.1 بنية Universal التي تدعم Intel وApple Silicon معًا، بينما تدعم حزمة الإصدار 1.0.0 المؤرشفة Apple Silicon (`arm64`) فقط.

## الميزات

-   محادثة بالذكاء الاصطناعي
-   وضع Agent للمهام متعددة الخطوات
-   تكامل مع واجهة برمجة تطبيقات Cloud AI
-   تطبيق سطح مكتب متعدد المنصات
-   إصدارات لمعمارية متعددة
-   واجهة رسومية
-   دعم لغات متعددة

## وضع Agent

يمكن لوضع Agent تقسيم الهدف إلى خطوات، واستخدام الأدوات التي فعّلها المستخدم، وإجراء تغييرات ضمن النطاق المصرّح به، والتحقق من النتيجة عندما يكون ذلك ممكنًا. لا يمنح هذا الوضع صلاحيات إضافية، وينبغي أن يطلب التأكيد قبل الإجراءات الحساسة أو المدمّرة. راجع [دليل وضع Agent](../docs/AGENT_MODE.md).

## تفاصيل المنصات

| المنصة | حالة المعمارية والحزم | التثبيت والقيود |
| --- | --- | --- |
| Windows | يستهدف 1.0.1 معماريتي x64 وARM64 ويستخدم ZIP افتراضيًا. يحتفظ الأرشيف بملف ZIP القديم 1.0.0 لمعمارية x64. | يجب فك ضغط ZIP بالكامل قبل تشغيل التطبيق. |
| Linux | يستهدف 1.0.1 معماريتي x86_64 وARM64 ويستخدم ZIP افتراضيًا. حزم 1.0.0 للمعماريتين مؤرشفة. | قد يحتوي ZIP على AppImage أو DEB أو RPM أو TAR.GZ. يحتاج AppImage إلى صلاحية التنفيذ، وتُثبّت DEB وRPM بمدير حزم النظام. |
| macOS | يستخدم 1.0.1 بنية Universal لـ Intel وApple Silicon ويُنشر كملف ZIP افتراضيًا؛ يقتصر 1.0.0 القديم على Apple Silicon (`arm64`). | فك ضغط ZIP للحصول على التطبيق. التطبيق غير موقّع حاليًا وقد يتطلب سماحًا يدويًا في إعدادات أمان macOS. |
| HarmonyOS | يستخدم إصدار 1.0.1 ملف ZIP افتراضيًا؛ يتم التثبيت عبر ملف HAP المتوافق والموقّع داخل الحزمة. حزم 1.0.0 المؤرشفة هي بنيات debug تقتصر على `2in1`. | تستهدف حزم HAP القديمة API `60101024`، ويتطلب التثبيت نظامًا متوافقًا وتوقيعًا صالحًا. راجع [ملاحظات HarmonyOS](../docs/HARMONYOS.md). |
| OpenHarmony | يستخدم إصدار 1.0.1 ملف ZIP افتراضيًا؛ يتطلب التثبيت ملف HAP متوافقًا مع OpenHarmony من الحزمة. | يلزم توقيع متوافق واختبار الجهاز. لا تستخدم حزمة HarmonyOS 1.0.0 المؤرشفة كحزمة OpenHarmony. |

## التثبيت

### Linux

AppImage:

1.  نزّل حزمة ZIP الافتراضية لنظام Linux وفك ضغطها، ثم اختر ملف AppImage المطابق لمعمارية جهازك.
2.  أضف صلاحية التنفيذ:

``` bash
chmod +x CloudAI.AppImage
```

3.  شغّل التطبيق:

``` bash
./CloudAI.AppImage
```

يمكن تثبيت حزم .deb باستخدام:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

إصدار macOS غير موقّع حاليًا بشهادة Apple Developer.

عند فتح التطبيق للمرة الأولى، قد يحتاج المستخدم إلى السماح بتشغيله يدويًا في إعدادات الأمان في macOS.

### HarmonyOS

تم بناء إصدار HarmonyOS باستخدام سلسلة أدوات التطوير الرسمية الخاصة بـ HarmonyOS.

يُستخدم DevEco Studio للتطوير والتغليف. تُبنى تطبيقات HarmonyOS كحزم HAP/App وتتطلب إعداد توقيع مناسب قبل التوزيع.
