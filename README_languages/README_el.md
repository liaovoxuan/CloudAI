# CloudAI

Το CloudAI είναι ένας βοηθός τεχνητής νοημοσύνης για πολλαπλές πλατφόρμες.

> **Κατάσταση έκδοσης 1.0.1:** Η λειτουργία Agent υποστηρίζει εργασίες πολλαπλών βημάτων και τα πακέτα εφαρμογής χρησιμοποιούν από προεπιλογή μορφή ZIP. Τα προηγούμενα πακέτα 1.0.0 διατηρούνται στο [αρχείο παλαιότερων εκδόσεων](../Releases/Legacy/v1.0.0/). Δείτε τη [λειτουργία Agent](../docs/AGENT_MODE.md) και τους [περιορισμούς του HarmonyOS](../docs/HARMONYOS.md).

> **macOS:** Η έκδοση 1.0.1 χρησιμοποιεί καθολική δόμηση Universal για Intel και Apple Silicon, ενώ το αρχειοθετημένο πακέτο 1.0.0 υποστηρίζει μόνο Apple Silicon (`arm64`).

## Δυνατότητες

-   Συνομιλία με τεχνητή νοημοσύνη
-   Λειτουργία Agent για εργασίες πολλαπλών βημάτων
-   Ενσωμάτωση με το Cloud AI API
-   Εφαρμογή επιφάνειας εργασίας για πολλαπλές πλατφόρμες
-   Εκδόσεις για πολλαπλές αρχιτεκτονικές
-   Γραφικό περιβάλλον
-   Υποστήριξη πολλών γλωσσών

## Λειτουργία Agent

Η λειτουργία Agent μπορεί να χωρίζει έναν στόχο σε βήματα, να χρησιμοποιεί τα εργαλεία που έχει ενεργοποιήσει ο χρήστης, να πραγματοποιεί εξουσιοδοτημένες αλλαγές και να επαληθεύει το αποτέλεσμα όπου είναι δυνατό. Δεν παρέχει πρόσθετα δικαιώματα και θα πρέπει να ζητά επιβεβαίωση πριν από ευαίσθητες ή καταστροφικές ενέργειες. Δείτε τον [οδηγό λειτουργίας Agent](../docs/AGENT_MODE.md).

## Εγκατάσταση

### Linux

AppImage:

1.  Κατεβάστε και αποσυμπιέστε το προεπιλεγμένο πακέτο ZIP για Linux και, στη συνέχεια, επιλέξτε το AppImage για την αρχιτεκτονική σας.
2.  Προσθέστε δικαίωμα εκτέλεσης:

``` bash
chmod +x CloudAI.AppImage
```

3.  Εκτελέστε την εφαρμογή:

``` bash
./CloudAI.AppImage
```

Τα πακέτα .deb μπορούν να εγκατασταθούν με:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

Η έκδοση για macOS δεν είναι προς το παρόν υπογεγραμμένη με πιστοποιητικό Apple Developer.

Κατά το πρώτο άνοιγμα, οι χρήστες ίσως χρειαστεί να επιτρέψουν την εφαρμογή χειροκίνητα στις ρυθμίσεις ασφαλείας του macOS.

### HarmonyOS

Η έκδοση για HarmonyOS έχει δημιουργηθεί με την επίσημη αλυσίδα εργαλείων ανάπτυξης του HarmonyOS.

Η ανάπτυξη και η συσκευασία γίνονται στο DevEco Studio. Οι εφαρμογές HarmonyOS δημιουργούνται ως πακέτα HAP/App και απαιτούν σωστή διαμόρφωση υπογραφής πριν από τη διανομή.
