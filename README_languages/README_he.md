# CloudAI

CloudAI הוא עוזר בינה מלאכותית חוצה פלטפורמות.

> **מצב גרסה 1.0.1:** מצב Agent תומך במשימות מרובות שלבים וחבילות היישום משתמשות ב-ZIP כברירת מחדל. חבילות 1.0.0 הקודמות נשמרות ב[ארכיון הגרסאות הישנות](../Releases/Legacy/v1.0.0/). ראו [מצב Agent](../docs/AGENT_MODE.md) ו[מגבלות HarmonyOS](../docs/HARMONYOS.md).

> **macOS:** גרסה 1.0.1 משתמשת בבניית Universal עבור Intel ועבור Apple Silicon, ואילו חבילת 1.0.0 שבארכיון תומכת רק ב-Apple Silicon (`arm64`).

## תכונות

-   שיחה עם בינה מלאכותית
-   מצב Agent למשימות מרובות שלבים
-   אינטגרציה עם Cloud AI API
-   אפליקציית שולחן עבודה לריבוי פלטפורמות
-   בניות לריבוי ארכיטקטורות
-   ממשק גרפי
-   תמיכה בריבוי שפות

## מצב Agent

מצב Agent יכול לחלק יעד לשלבים, להשתמש בכלים שהמשתמש הפעיל, לבצע שינויים מורשים ולאמת את התוצאה במידת האפשר. המצב אינו מעניק הרשאות נוספות, ועליו לבקש אישור לפני פעולות רגישות או הרסניות. למידע נוסף ראו את [המדריך למצב Agent](../docs/AGENT_MODE.md).

## פלטפורמות נתמכות

### שולחן עבודה

-   Windows x64
-   Windows ARM64
-   macOS Universal (Intel + Apple Silicon) — v1.0.1
-   macOS Apple Silicon — legacy v1.0.0
-   Linux x86_64
-   Linux ARM64

### פלטפורמות אחרות

-   HarmonyOS
-   OpenHarmony

## התקנה

### Linux

AppImage:

1.  הורידו וחלצו את חבילת ה-ZIP המוגדרת כברירת מחדל עבור Linux, ולאחר מכן בחרו את קובץ ה-AppImage המתאים לארכיטקטורה שלכם.
2.  הוסיפו הרשאת הרצה:

``` bash
chmod +x CloudAI.AppImage
```

3.  הפעילו את היישום:

``` bash
./CloudAI.AppImage
```

ניתן להתקין חבילות .deb באמצעות:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

גרסת macOS אינה חתומה כעת בתעודה של Apple Developer.

בפתיחה הראשונה, ייתכן שהמשתמשים יצטרכו לאשר את היישום ידנית בהגדרות האבטחה של macOS.

### HarmonyOS

גרסת HarmonyOS נבנתה עם שרשרת כלי הפיתוח הרשמית של HarmonyOS.

הפיתוח והאריזה משתמשים ב-DevEco Studio. יישומי HarmonyOS נבנים כחבילות HAP/App ודורשים תצורת חתימה מתאימה לפני ההפצה.
