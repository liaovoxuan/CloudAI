# CloudAI

CloudAI एक क्रॉस-प्लेटफ़ॉर्म AI सहायक है।

> **संस्करण 1.0.1 की स्थिति:** Agent मोड बहु-चरणीय कार्यों का समर्थन करता है और ऐप्लिकेशन पैकेज डिफ़ॉल्ट रूप से ZIP में उपलब्ध हैं। पिछले 1.0.0 पैकेज [पुराने संस्करणों के संग्रह](../Releases/Legacy/v1.0.0/) में सुरक्षित हैं। [Agent मोड](../docs/AGENT_MODE.md) और [HarmonyOS की सीमाएँ](../docs/HARMONYOS.md) देखें।

> **macOS:** संस्करण 1.0.1 Intel और Apple Silicon दोनों के लिए Universal बिल्ड का उपयोग करता है, जबकि संग्रहित 1.0.0 पैकेज केवल Apple Silicon (`arm64`) का समर्थन करता है।

## विशेषताएँ

-   AI वार्तालाप
-   बहु-चरणीय कार्यों के लिए Agent मोड
-   क्लाउड AI API एकीकरण
-   बहु-प्लेटफ़ॉर्म डेस्कटॉप ऐप्लिकेशन
-   बहु-आर्किटेक्चर बिल्ड
-   ग्राफ़िकल इंटरफ़ेस
-   बहुभाषी समर्थन

## Agent मोड

Agent मोड किसी लक्ष्य को चरणों में बाँट सकता है, उपयोगकर्ता द्वारा सक्षम किए गए टूल का उपयोग कर सकता है, अधिकृत बदलाव कर सकता है और जहाँ संभव हो परिणाम की पुष्टि कर सकता है। यह अपने आप अतिरिक्त अनुमतियाँ नहीं देता और संवेदनशील या विनाशकारी कार्रवाइयों से पहले पुष्टि माँगनी चाहिए। [Agent मोड मार्गदर्शिका](../docs/AGENT_MODE.md) देखें।

## इंस्टॉलेशन

### Linux

AppImage:

1.  Linux का डिफ़ॉल्ट ZIP पैकेज डाउनलोड करके निकालें, फिर अपने आर्किटेक्चर के लिए सही AppImage चुनें।
2.  निष्पादन की अनुमति जोड़ें:

``` bash
chmod +x CloudAI.AppImage
```

3.  ऐप्लिकेशन चलाएँ:

``` bash
./CloudAI.AppImage
```

deb पैकेज इस प्रकार इंस्टॉल किए जा सकते हैं:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

macOS संस्करण वर्तमान में Apple Developer प्रमाणपत्र से हस्ताक्षरित नहीं है।

पहली बार खोलते समय उपयोगकर्ताओं को macOS सुरक्षा सेटिंग्स में ऐप्लिकेशन को मैन्युअल रूप से अनुमति देनी पड़ सकती है।

### HarmonyOS

HarmonyOS संस्करण आधिकारिक HarmonyOS विकास टूलचेन के साथ बनाया गया है।

विकास और पैकेजिंग में DevEco Studio का उपयोग किया जाता है। HarmonyOS ऐप्लिकेशन HAP/App पैकेज के रूप में बनाए जाते हैं और वितरण से पहले उचित हस्ताक्षर कॉन्फ़िगरेशन की आवश्यकता होती है।
