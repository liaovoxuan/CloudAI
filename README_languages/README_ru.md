# CloudAI

CloudAI — кроссплатформенный ИИ-ассистент.

> **Статус версии 1.0.1:** Режим Agent поддерживает многоэтапные задачи, а пакеты приложения по умолчанию используют формат ZIP. Предыдущие пакеты 1.0.0 сохранены в [архиве](../Releases/Legacy/v1.0.0/). См. описание [режима Agent](../docs/AGENT_MODE.md) и [ограничений HarmonyOS](../docs/HARMONYOS.md).

> **macOS:** Версия 1.0.1 использует сборку Universal для Intel и Apple Silicon, а архивный пакет версии 1.0.0 поддерживает только Apple Silicon (`arm64`).

## Возможности

-   Общение с ИИ
-   Режим Agent для многоэтапных задач
-   Интеграция с API Cloud AI
-   Кроссплатформенное настольное приложение
-   Сборки для нескольких архитектур
-   Графический интерфейс
-   Поддержка нескольких языков

## Режим Agent

Режим Agent может разбить цель на этапы, использовать включённые пользователем инструменты, вносить разрешённые изменения и по возможности проверять результат. Сам по себе он не предоставляет дополнительных прав и должен запрашивать подтверждение перед чувствительными или разрушительными действиями. Подробнее см. в [руководстве по режиму Agent](../docs/AGENT_MODE.md).

## Установка

### Linux

AppImage:

1.  Скачайте и распакуйте стандартный ZIP-пакет для Linux, затем выберите AppImage для своей архитектуры.
2.  Добавьте право на выполнение:

``` bash
chmod +x CloudAI.AppImage
```

3.  Запустите приложение:

``` bash
./CloudAI.AppImage
```

Пакеты .deb можно установить командой:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

Версия для macOS в настоящее время не подписана сертификатом Apple Developer.

При первом запуске пользователям может потребоваться вручную разрешить приложение в настройках безопасности macOS.

### HarmonyOS

Версия для HarmonyOS собрана с официальным набором инструментов разработки HarmonyOS.

Для разработки и упаковки используется DevEco Studio. Приложения HarmonyOS собираются в виде пакетов HAP/App и требуют правильной настройки подписи перед распространением.
