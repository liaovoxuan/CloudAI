# CloudAI

CloudAI เป็นผู้ช่วย AI ข้ามแพลตฟอร์ม

> **สถานะเวอร์ชัน 1.0.1:** โหมด Agent รองรับงานหลายขั้นตอน และแพ็กเกจแอปพลิเคชันใช้รูปแบบ ZIP เป็นค่าเริ่มต้น ส่วนแพ็กเกจ 1.0.0 รุ่นก่อนถูกเก็บไว้ใน[คลังเวอร์ชันเก่า](../Releases/Legacy/v1.0.0/) โปรดดู[โหมด Agent](../docs/AGENT_MODE.md) และ[ข้อจำกัดของ HarmonyOS](../docs/HARMONYOS.md)

> **macOS:** เวอร์ชัน 1.0.1 ใช้บิลด์แบบ Universal ซึ่งรองรับทั้ง Intel และ Apple Silicon ส่วนแพ็กเกจ 1.0.0 ที่เก็บถาวรรองรับเฉพาะ Apple Silicon (`arm64`)

## ฟีเจอร์

-   การสนทนาด้วย AI
-   โหมด Agent สำหรับงานหลายขั้นตอน
-   การเชื่อมต่อกับ Cloud AI API
-   แอปพลิเคชันเดสก์ท็อปแบบหลายแพลตฟอร์ม
-   การบิลด์สำหรับหลายสถาปัตยกรรม
-   ส่วนติดต่อผู้ใช้แบบกราฟิก
-   รองรับหลายภาษา

## โหมด Agent

โหมด Agent สามารถแบ่งเป้าหมายออกเป็นขั้นตอน ใช้เครื่องมือที่ผู้ใช้เปิดใช้งาน ดำเนินการเปลี่ยนแปลงภายในขอบเขตที่ได้รับอนุญาต และตรวจสอบผลลัพธ์เมื่อทำได้ โหมดนี้ไม่ได้ให้สิทธิ์เพิ่มเติม และควรขอคำยืนยันก่อนดำเนินการที่มีความละเอียดอ่อนหรืออาจทำลายข้อมูล โปรดดู[คู่มือโหมด Agent](../docs/AGENT_MODE.md)

## แพลตฟอร์มที่รองรับ

### เดสก์ท็อป

-   Windows x64
-   Windows ARM64

-   macOS Apple Silicon — legacy v1.0.0
-   Linux x86_64

### แพลตฟอร์มอื่น ๆ

-   OpenHarmony

## รายละเอียดแพลตฟอร์ม

| แพลตฟอร์ม | สถาปัตยกรรมและสถานะแพ็กเกจ | การติดตั้งและข้อจำกัด |
| --- | --- | --- |
| Windows | เวอร์ชัน 1.0.1 รองรับ x64 และ ARM64 และใช้ ZIP เป็นค่าเริ่มต้น คลังเก็บมี ZIP 1.0.0 รุ่นเก่าสำหรับ x64 | แตกไฟล์ ZIP ให้ครบก่อนเรียกใช้งาน |
| Linux | เวอร์ชัน 1.0.1 รองรับ x86_64 และ ARM64 และใช้ ZIP เป็นค่าเริ่มต้น แพ็กเกจ 1.0.0 ของทั้งสองสถาปัตยกรรมถูกเก็บถาวร | ZIP อาจมี AppImage, DEB, RPM หรือ TAR.GZ โดย AppImage ต้องมีสิทธิ์เรียกใช้งาน ส่วน DEB และ RPM ติดตั้งผ่านตัวจัดการแพ็กเกจ |
| macOS | เวอร์ชัน 1.0.1 ใช้บิลด์ Universal สำหรับ Intel และ Apple Silicon และเผยแพร่เป็น ZIP โดยค่าเริ่มต้น ส่วน 1.0.0 รองรับเฉพาะ Apple Silicon (`arm64`) | แตก ZIP เพื่อรับแอปพลิเคชัน ซึ่งยังไม่ได้ลงนามและอาจต้องอนุญาตด้วยตนเองใน macOS |
| HarmonyOS | เวอร์ชัน 1.0.1 เผยแพร่เป็น ZIP โดยค่าเริ่มต้น และติดตั้ง HAP ที่เข้ากันได้และลงนามแล้วภายใน ส่วน HAP 1.0.0 ที่เก็บถาวรเป็นบิลด์ debug สำหรับ `2in1` เท่านั้น | HAP รุ่นเก่ากำหนดเป้าหมาย API `60101024` ต้องใช้ระบบที่เข้ากันได้และลายเซ็นที่ถูกต้อง โปรดดู[หมายเหตุ HarmonyOS](../docs/HARMONYOS.md) |
| OpenHarmony | เวอร์ชัน 1.0.1 เผยแพร่เป็น ZIP โดยค่าเริ่มต้น และติดตั้ง HAP ที่เข้ากันได้กับ OpenHarmony ภายใน | ต้องมีลายเซ็นที่เข้ากันได้และการทดสอบอุปกรณ์ ห้ามใช้ HarmonyOS HAP 1.0.0 ที่เก็บถาวรเป็นแพ็กเกจ OpenHarmony |

## การติดตั้ง

### Linux

AppImage:

1.  ดาวน์โหลดและแตกไฟล์แพ็กเกจ ZIP เริ่มต้นสำหรับ Linux จากนั้นเลือก AppImage ที่ตรงกับสถาปัตยกรรมของคุณ
2.  เพิ่มสิทธิ์ในการเรียกใช้งาน:

``` bash
chmod +x CloudAI.AppImage
```

3.  เรียกใช้งานแอปพลิเคชัน:

``` bash
./CloudAI.AppImage
```

แพ็กเกจ .deb สามารถติดตั้งได้ด้วยคำสั่ง:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

เวอร์ชัน macOS ในปัจจุบันยังไม่ได้ลงนามด้วยใบรับรอง Apple Developer

เมื่อเปิดใช้งานครั้งแรก ผู้ใช้อาจต้องอนุญาตแอปพลิเคชันด้วยตนเองในการตั้งค่าความปลอดภัยของ macOS

### HarmonyOS

เวอร์ชัน HarmonyOS สร้างด้วยชุดเครื่องมือพัฒนาอย่างเป็นทางการของ HarmonyOS

ใช้ DevEco Studio ในการพัฒนาและจัดทำแพ็กเกจ แอปพลิเคชัน HarmonyOS ถูกสร้างเป็นแพ็กเกจ HAP/App และต้องมีการกำหนดค่าลายเซ็นที่ถูกต้องก่อนเผยแพร่
