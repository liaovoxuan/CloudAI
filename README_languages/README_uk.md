> **Стан версії 1.0.1:** Режим Agent підтримує багатоетапні завдання, а пакунки застосунку типово використовують формат ZIP. Попередні пакунки 1.0.0 збережено в [архіві](../Releases/Legacy/v1.0.0/). Див. опис [режиму Agent](../docs/AGENT_MODE.md) та [обмежень HarmonyOS](../docs/HARMONYOS.md).

## Режим Agent

Режим Agent може розділити мету на етапи, використовувати ввімкнені користувачем інструменти, вносити дозволені зміни та за можливості перевіряти результат. Сам по собі він не надає додаткових прав і має запитувати підтвердження перед чутливими або руйнівними діями. Докладніше див. у [посібнику з режиму Agent](../docs/AGENT_MODE.md).

## Встановлення

### Linux

AppImage:

1.  Завантажте та розпакуйте типовий ZIP-пакунок для Linux, а потім виберіть AppImage для своєї архітектури.
2.  Додайте право на виконання:

``` bash
chmod +x CloudAI.AppImage
```

3.  Запустіть застосунок:

``` bash
./CloudAI.AppImage
```

Пакунки .deb можна встановити командою:

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

Версія для macOS наразі не підписана сертифікатом Apple Developer.

Під час першого відкриття користувачам може знадобитися вручну дозволити застосунок у налаштуваннях безпеки macOS.

### HarmonyOS

Версія для HarmonyOS зібрана за допомогою офіційного набору інструментів розробки HarmonyOS.

Для розробки та пакування використовується DevEco Studio. Застосунки HarmonyOS збираються як пакети HAP/App і потребують належного налаштування підпису перед розповсюдженням.
