# CloudAI

CloudAI 是一个跨平台 AI 助手。

## 功能

-   AI 对话
-   云端 AI API 接入
-   多平台桌面应用
-   多架构构建
-   图形化界面
-   多语言支持

## 支持平台

桌面：

-   Windows x64
-   Windows ARM64
-   macOS Intel
-   macOS Apple Silicon
-   Linux x86_64
-   Linux ARM64

其他：

-   HarmonyOS
-   OpenHarmony

## 安装

### Linux

AppImage：

``` bash
chmod +x CloudAI.AppImage
./CloudAI.AppImage
```

Deb：

``` bash
sudo apt install ./CloudAI.deb
```

### macOS

macOS 版本目前未使用 Apple Developer 证书签名。

首次打开时，需要在系统安全设置中手动允许应用运行。

### HarmonyOS

HarmonyOS 版本使用官方开发工具链构建。

应用通过 DevEco Studio 开发，最终生成 HAP/App
