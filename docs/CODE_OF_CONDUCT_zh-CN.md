# 行为准则

## 我们的承诺

CloudAI 致力于为所有参与者提供友好、安全且免受骚扰的社区环境，不因身份、背景、经验或能力而区别对待。

## 应有行为

- 保持尊重、耐心和建设性。
- 接纳不同观点，并提供可执行的反馈。
- 针对观点和代码提出意见，不攻击个人。
- 对自己的行为负责，修正错误，并尊重合理边界。
- 保护隐私，分享他人信息前先获得同意。

## 不可接受的行为

- 骚扰、威胁、跟踪或持续扰乱社区活动。
- 歧视、侮辱、性暗示或贬损性的语言与图像。
- 与项目无关的人身或政治攻击。
- 未经允许公开他人的私人信息。
- 故意滥用项目基础设施或举报渠道。
- 其他在专业社区中可被合理认定为不当的行为。

## 适用范围

本准则适用于仓库的 Issue、Pull Request、代码审查、讨论、提交及其他项目空间，也适用于个人以 CloudAI 官方代表身份公开活动的场景。

## 举报方式

机密举报请使用仓库的[私密漏洞报告](https://github.com/liaovoxuan/CloudAI/security/advisories/new)，并在标题前添加 `[Code of Conduct]`。不要在公开 Issue 中提供敏感事件细节。如果私密报告功能不可用，可以提交一个不包含人员姓名或事件详情的简短 Issue，请求维护者提供私下联系方式。

维护者会在合理范围内以保密、公平的方式处理举报。善意举报者不会因举报行为受到处罚。

## 执行措施

维护者可根据严重程度和历史情况编辑或删除内容、私下提醒或警告、暂时限制参与，或永久禁止参与。为保护社区，必要时可立即采取限制措施。禁止对举报者进行报复。

本准则参考 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，并根据 CloudAI 当前可用的举报渠道进行了调整。
