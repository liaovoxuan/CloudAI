# 隐私政策

最后更新：2026-09-19

## 适用范围

本政策说明 CloudAI 应用及本仓库涉及的隐私事项。CloudAI 是客户端应用，可以连接用户选择并配置的 AI 服务。

## 发送给 AI 服务的数据

配置网络 AI 服务后，CloudAI 可能发送处理请求所需的提示词、对话内容、附件和技术请求元数据。服务提供商会依据其自身的隐私政策、保留规则和账户设置处理数据。发送机密信息前，请先查阅对应条款。

查询余额时，应用可能访问所选 AI 服务商的账户或用量接口。使用 Agent 的网页搜索操作时，搜索词会发送至 DuckDuckGo；打开外部网址时，系统浏览器会连接对应站点。这些第三方可能收到 IP 地址等常规网络元数据。

Agent 模式可能处理用户纳入任务范围的其他文件或命令输出。允许访问敏感数据前，请检查请求执行的操作和权限。

第三方插件在本地以应用进程的权限运行。请只安装可信插件，并检查插件自身的网络连接和数据处理方式。

## 凭据与本地数据

API Key 和服务凭据属于敏感信息。用户应保护本地配置和备份，不要共享凭据，并及时撤销可能已经泄露的凭据。具体存储方式可能因应用版本和平台而异。

在仓库所含的 CloudAI 1.0.1 桌面端、Python 和 C++ 源码中，API Key 会在状态输出中被掩码处理，但磁盘文件使用可逆混淆而非平台级加密。能够读取该本地文件的人可能恢复其中的密钥。

日志、崩溃报告和截图可能包含提示词、文件路径、系统详情或标识符。提交 Issue 前应检查并脱敏。

## 仓库交互

提交到公开 Issue、Pull Request 或讨论区的信息会公开显示，并依据 GitHub 政策保留。安全敏感信息应按照[安全政策](SECURITY_zh-CN.md)私下提交。

## 第三方

CloudAI 安装包可能包含第三方组件，用户也可能配置第三方 AI 服务。这些第三方适用各自的条款和隐私做法。许可信息参见[第三方声明](../THIRD_PARTY_NOTICES.md)。

## 政策变更与咨询

本政策的重大修改应记录在版本控制中。非敏感的隐私问题可以提交 [GitHub Issue](https://github.com/liaovoxuan/CloudAI/issues)，但不要在公开 Issue 中提供个人信息或安全敏感内容。
