# Support

## Where to ask

- Use [GitHub Issues](https://github.com/liaovoxuan/CloudAI/issues) for
  reproducible bugs and focused feature requests.
- Use the [security reporting process](SECURITY.md) for vulnerabilities.
- Use the [Code of Conduct reporting process](CODE_OF_CONDUCT.md) for private
  conduct reports.

Before opening an issue, search existing reports and read the relevant README
platform notes.

## Information to include

- CloudAI version and package filename or format;
- operating system version and device architecture;
- installation method and configured AI provider;
- exact reproduction steps, expected behavior and actual behavior;
- sanitized logs, screenshots or error messages; and
- troubleshooting steps already attempted.

Never post API keys, tokens, private prompts, personal data or unredacted logs.

## Support scope

The project provides best-effort community support without a guaranteed
response time. The latest version is prioritized. Legacy 1.0.0 packages may be
used for historical reference but do not receive routine support or security
fixes.

Support does not cover outages, billing, account access or policy decisions of
third-party AI providers. Contact the relevant provider for those issues.
