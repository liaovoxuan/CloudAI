# 支持

## 获取支持

- 可复现 Bug 和范围明确的功能建议请使用 [GitHub Issues](https://github.com/liaovoxuan/CloudAI/issues)。
- 安全漏洞请使用[安全报告流程](SECURITY_zh-CN.md)。
- 需要保密的行为准则举报请使用[行为准则中的举报流程](CODE_OF_CONDUCT_zh-CN.md)。

提交 Issue 前，请先搜索现有报告并阅读 README 中对应平台的说明。

## 需要提供的信息

- CloudAI 版本及安装包文件名或格式；
- 操作系统版本和设备架构；
- 安装方式及配置的 AI 服务提供商；
- 完整复现步骤、预期行为和实际行为；
- 脱敏后的日志、截图或错误信息；
- 已经尝试过的排查步骤。

不要公开 API Key、令牌、私密提示词、个人信息或未经脱敏的日志。

## 支持范围

项目提供尽力而为的社区支持，不保证响应时间。问题处理会优先考虑最新版本。旧版 1.0.0 安装包仅供历史参考，不提供常规支持或安全修复。

第三方 AI 服务的故障、计费、账户访问或政策决定不属于本项目支持范围，请联系对应服务提供商。
